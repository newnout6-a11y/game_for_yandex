# ПОТОК

Аркадная гонка для браузера и Яндекс Игр. Дневное загородное шоссе, трафик, близкие обгоны и нитро. WebGL 2 / Three.js: детализированная модель Ferrari 458 Italia, PBR-асфальт и обочины, HDR-небо, холмистый рельеф, кроны деревьев из готовой модели, тени и частицы столкновения. Все модели, текстуры и декодер Draco входят в сборку; внешних CDN и шрифтов нет. Звук синтезируется через Web Audio.

## Запуск

Нужен Node.js 22 или новее.

```powershell
npm.cmd ci
npm.cmd run dev
```

Открыть http://127.0.0.1:4173. Открытие `index.html` через `file://` не подходит для ES-модулей.

## Как играть

- W / ↑ — удерживать газ; S / ↓ — тормоз. Старт с места. После отпускания газа машина катится и постепенно замедляется; заднего хода нет.
- A / D или ← / → — удерживать руль. Поворот колёс и направление движения меняются постепенно, положение между полосами свободное. При отпускании руль возвращается в ноль, машина не подтягивается к центру полосы.
- Пробел вместе с газом — нитро. Ускорение работает на ходу и расходует заряд. Тормоз имеет приоритет над газом и нитро.
- Телефон: кнопки руля слева, педали справа; допускается одновременное удержание. Кнопка НИТРО расположена над педалями. Свайп даёт короткий поворот руля.
- Баллон даёт +22% нитро и 50 очков с учётом множителя. Близкие обгоны увеличивают множитель до ×5 на 5 секунд.
- Цель 1 500 м даёт 1 000 очков один раз. Рекорды двух режимов сохраняются отдельно.
- Esc / P — пауза. При сворачивании, потере фокуса и рекламе нажатия сбрасываются. Возврат требует явного продолжения и нового нажатия газа.
- Второй шанс один на заезд. После него машина стоит, ближайшие препятствия убраны, действует 2,5 секунды защиты.

### События

После первых 80 м начинается чередование трёх событий. Предупреждение показывает задачу заранее.

1. Дорожные работы: крайняя полоса перекрыта конусами и ограждениями. Конус замедляет машину и отнимает 50 очков; ограждение вызывает столкновение. Чистый проезд — 300 очков и +15% нитро.
2. Контрольная точка: нужно успеть пройти между флагами за 18 секунд. Проезд мимо ворот или опоздание не даёт награды; правильный проезд — 500 очков и +15% нитро.
3. Тормозящая колонна: четыре машины появляются вдали, затем снижают скорость со стоп-сигналами. Нужно обойти всю колонну за 35 секунд; награда — 400 очков и +15% нитро.

Очки событий умножаются на коэффициент режима. При продолжении после аварии активное событие считается не пройденным. Следующая задача появляется через 120 м после завершения предыдущей. Обычный трафик не заменяется при начале колонны. Водители сзади тормозят перед остановившейся машиной игрока.

Три дневных окружения — «Загородное шоссе», «Сосновый бор», «Открытая дорога» — отличаются плотностью леса. «Час пик» повышает максимальную скорость, плотность трафика и коэффициент очков.

## Проверки

```powershell
npm.cmd test
npm.cmd run check
npx.cmd playwright install webkit
npm.cmd run test:browser
npm.cmd run build
node scripts/browser-check.mjs --dist
```

Браузерные сценарии используют установленный Google Chrome и Playwright WebKit. Скриншоты и JSON-отчёты сохраняются в `output/playwright/`. WebKit с профилем iPhone проверяет поведение движка и мобильной разметки; это не испытание на физическом iPhone. Автоматическая проверка axe охватывает применимые правила интерфейса и не является сертификатом доступности игры.

## Сборка для Яндекс Игр

`npm.cmd run build` создаёт `dist/` и `output/potok-yandex.zip`, с `index.html` в корне архива. В архив входят HTML, игровые модули, стили, локальные модели, текстуры, декодер и лицензии. Исходная версия до переработки сохранена отдельно: `output/backups/original-2026-10-15.zip`.

На платформе SDK загружается динамически по `/sdk.js`. В обычном локальном запуске SDK не загружается. Старт блокируется до завершения загрузки всех локальных ресурсов; при ошибке доступна повторная загрузка. Game Ready отправляется только после готовности ресурсов и инициализации SDK. Отсутствие SDK не блокирует игру. События платформы, фокус, видимость, ручная пауза и реклама имеют независимые причины остановки. GameplayAPI соответствует фактической работе симуляции. Реклама не показывается во время заезда; полноэкранная — только при повторном запуске после заезда от 30 секунд, не чаще раза в минуту. Повторный показ охраняется блокировкой, ошибки и таймауты обрабатываются без выдачи ложной награды.

SDK и рекламные переходы проверяются с тестовым SDK. Перед публикацией остаётся реальная проверка в черновике приложения Яндекс Игр: загрузчик, Game Ready, реклама и мобильные устройства. Сам архив не публикуется автоматически.

Официальные контракты: [подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about), [готовность и геймплей](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events), [события](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events), [реклама](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv).

## Структура

| Папка / модуль | Назначение |
|---|---|
| `src/game.js` | Чистая симуляция: плотный стартовый трафик, генерация, движение, столкновения, бонусы |
| `src/world.js` | Дневной 3D-мир, камера, дорога, рельеф, освещение, деревья и частицы |
| `src/input.js`, `motion.js` | Удержание нескольких органов управления и стабильная камера с плавными переходами |
| `src/car.js` | Копии модели автомобиля, материалы, масштаб и анимация колёс |
| `src/main.js` | Игровые переходы, ввод и связывание модулей |
| `src/ui.js` | Меню, HUD, диалоги и управление фокусом |
| `src/lifecycle.js`, `sdk.js`, `ads.js` | Паузы и интеграция платформы |
| `src/storage.js`, `audio.js` | Сохранения и синтез звука |
| `tokens/theme.json` | Общие токены интерфейса; `styles/theme.css` генерируется при сборке |
| `tests/` | Тесты поведения и регрессий |
| `scripts/` | Локальный сервер, проверки, браузерные сценарии и сборка |
| `docs/` | Решения и условия выпуска |

Плотность деревьев трёх окружений определена в `src/config.js`. Размеры 3D-геометрии — мировые координаты, а не CSS-токены интерфейса. Требуется WebGL 2. Лицензия Three.js включена в public/vendor/THREE-LICENSE.txt.

## Графические ресурсы

Ferrari 458 Italia — vicent091036, CC BY 4.0; загружена из примеров Three.js r183. Материалы дороги, грунта, травы, HDR-небо и модель Fir Sapling — Poly Haven, CC0. Полные источники и условия: [CREDITS](public/assets/CREDITS.txt); SHA-256 каждого ресурса: [manifest](public/assets/manifest.json). Прозрачные кроны запечены из модели в три 1024×1024 изображения для снижения нагрузки на мобильные GPU. В трафике используется одна базовая модель с разной окраской.

Готовые ресурсы включены в проект; обычная сборка не скачивает их заново. Для воспроизведения подготовки: `node scripts/prepare-assets.mjs`, затем `node scripts/bake-trees.mjs`. Нужны сеть и установленный Chrome. Исходная модель дерева остаётся в игнорируемой папке `output/assets-source/` и не попадает в ZIP. Геометрия машин, бонусов и частиц переиспользуется.

## Обновление управления 2026-10-16

Автоперестроения и автоматический разгон заменены ручным управлением. Камера не привязана к рулю или положению машины поперёк дороги. Сглаживание переходов зависит от времени кадра. Экспозиция 3D-сцены, яркость HDR-фона, солнечный и окружающий свет уменьшены. Результат смотрите в живом заезде; тесты не оценивают художественное качество.

HUD переделан под заезд: на компьютере справа внизу шкала 0–300 км/ч, стрелка и цифровая скорость связаны с симуляцией; рядом тонкий индикатор нитро. На телефоне скорость цифровая, показатели собраны сверху, руль и педали разнесены по краям. Неактивный множитель скрыт. Предупреждение о событии показывает реальную задачу и оставшуюся дистанцию, время или число машин. Меню использует простые переключатели маршрута без карточек и декоративных слоганов.

Дополнительные проверки: `node scripts/events-check.mjs --dist` создаёт изолированные визуальные сценарии всех событий, а `node scripts/check-landscape.mjs --dist` проверяет размещение органов управления в двух движках. Запись реального управления: `node scripts/record-drive.mjs` (для неё нужен работающий локальный сервер).
