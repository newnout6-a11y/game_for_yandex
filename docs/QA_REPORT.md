## Управление и камера

- Машина начинает с нулевой скорости. Газ разгоняет, отпускание газа даёт накат, тормоз имеет приоритет и не включает задний ход.
- Руль меняет угол и направление постепенно; автомобиль может находиться между полосами. Руление на месте не перемещает кузов. Границы дороги ограничивают движение.
- Симуляция согласуется при 60 и 120 Гц; камера — при 30, 60 и 120 Гц.
- Проверяются реальные WebGL-пиксели машины при удержании клавиш. В 50 последовательных кадрах руления нет скачков больше 15 CSS px; камера сохраняет ось дороги независимо от руля.
- Нитро работает с газом на ходу и расходует заряд между подборами. Торможение проверено по снижению скорости.
- На телефоне одновременные касания газа, руля, тормоза и нитро учитываются независимо. Отмена указателя освобождает удержание. Свайп даёт короткий импульс руля.
- Пауза и потеря фокуса сбрасывают ввод. После возвращения требуется продолжение и новое нажатие газа.

## События и трафик

- Дорожные работы: предупреждение, восемь конусов и два ограждения; проверены столкновения, однократный штраф и награда за чистый проезд.
- Контрольная точка: ворота реально отображаются; проверены положение кузова между флагами, время, промах и однократная награда.
- Колонна: четыре машины добавляются вдали без замены существующего трафика, тормозят со стоп-сигналами; награда только после обгона всех машин, таймаут не даёт награды.
- Проверены очередность событий, продолжение после аварии без бесплатного зачёта, достижение цели, близкие обгоны и заряды.
- Относительное движение трафика учитывает обе скорости. Машины сзади тормозят перед остановившимся игроком.

events-check.mjs создаёт изолированные состояния через настоящие Game, RoadRenderer и UI, не изменяя активный заезд. Его изображения подтверждают геометрию и показания, а не самостоятельное прохождение всех событий. В последней записи живого управления показаны дорожные работы и столкновение; она не используется как доказательство прохождения остальных событий.

## Интерфейс и графика

- Спидометр при старте показывает ноль; цифровая скорость, положение стрелки и заполнение шкалы соответствуют фактической скорости симуляции. Неактивный множитель скрыт.
- Проверены отсутствие горизонтального переполнения меню и взаимных наложений счёта, скорости, нитро и цели на 280×720, 320×780, 390×844, 414×896, 768×1024, 844×390, 1920×1080.
- Сенсорные органы управления остаются в пределах экрана. Отдельно проверена горизонтальная раскладка обоих движков.
- Axe: меню, справка, пауза, результат, мобильное меню и HUD во время игры; 0 нарушений выбранных автоматических правил. Контраст основной кнопки проверен в default/hover/focus/active. Диалоги удерживают фокус, закрываются по Esc и возвращают его.
- WebKit с профилем iPhone 13: машина обнаруживается по пикселям композиционного снимка всей страницы и перемещается после управления. Повороты portrait → landscape → portrait сохраняют сцену.
- Фиксированная внутренняя поверхность WebGL сохранена: изменение drawing buffer после старта раньше приводило к пропавшей сцене в композиторе WebKit. Аспект камеры и CSS-размер адаптируются отдельно.
- Проверены узлы кузова и колёс детализированной модели, независимые материалы экземпляров, анимация колёс и SHA-256 всех 13 художественных ресурсов.
- Повторные появления машин, зарядов и частиц не увеличивают число GPU-геометрий и общий размер пулов после прогрева.
- Загрузка блокирует старт и Game Ready до готовности ресурсов. Задержка модели, отказ HDR и успешная повторная загрузка проверены отдельно.
- В полном браузерном прогоне нет ошибок JS/HTTP и внешних запросов игровых ресурсов.

## Архив и артефакты

Дополнительно распакован ZIP через fflate.unzipSync: все 40 файлов побайтно совпали с dist и исходниками. Выполненная команда:

~~~powershell
@'
import assert from 'node:assert/strict';
import {readFile,readdir} from 'node:fs/promises';
import {unzipSync} from 'fflate';
const zip=unzipSync(await readFile('output/potok-yandex.zip'));
let count=0;
async function verify(dir,prefix=''){
  for(const entry of await readdir(dir,{withFileTypes:true})){
    const key=prefix+entry.name;
    if(entry.isDirectory())await verify(dir+'/'+entry.name,key+'/');
    else{
      const built=await readFile(dir+'/'+entry.name);
      assert.deepEqual(Buffer.from(zip[key]),built,key+' archive differs');
      assert.deepEqual(await readFile(key),built,key+' source differs');count++;
    }
  }
}
await verify('dist');
assert.equal(Object.keys(zip).length,count);
console.log('PASS: all '+count+' ZIP entries match dist and source byte for byte');
'@ | node --input-type=module
~~~
