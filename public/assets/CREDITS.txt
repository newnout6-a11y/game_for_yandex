Roadster Rocket reference reconstruction (roadster.glb)
Original project artwork, authored in Blender for this project in October 2026.
Editable source: art/roadster.blend. Rebuild: scripts/create_roadster.py,
scripts/roadster_geometry.py and scripts/roadster_cabin.py.
Original cabin PNG material/UI sources: art/textures/roadster-cabin-*.png;
the same maps are embedded in the runtime GLB.
Reference basis: user-supplied images and Tesla's current public Roadster media
https://www.tesla.com/roadster
https://www.youtube.com/watch?v=r5vsHHPVhJg
No downloaded manufacturer mesh, official photograph or factory CAD is included.
The selected Rocket variant is single-seat. Exact seat placement, unseen hardware,
working game dimensions and the wing mechanism are reconstructed, not verified
factory specifications. Visible geometry, glazing, upholstery, lighting, wing,
fans, wheels and nozzle apertures are modeled rather than photograph overlays.
The original screen artwork is illustrative, not a factory UI or live telemetry.
No manufacturer endorsement is implied. Flight, roll, fan speed and wing control
remain explicitly arcade/visual interpretations, not manufacturer control laws.
Technical scope and limitations: docs/ROADSTER_ROCKET_PLAN.md and
ROADSTER_ROCKET_UPDATE.md. Legacy revision reports describe earlier snapshots.
Scenic terrain/landmarks are original project code. The current traffic fleet is
original Blender project artwork (see fleet section below).
Legacy Ferrari asset remains in this source bundle with its attribution above;
it is not the active player or traffic model in the current game.

Blender traffic fleet, October 2026
Eight original vehicles: sedan, hatchback, SUV, delivery van, rigid box truck, articulated semi, tow truck and fire apparatus.
Original-project-artwork; no copied third-party vehicle mesh, photo texture, trademark or manufacturer CAD.
Editable sources: art/traffic/{sedan,hatch,suv,van,boxtruck,semi,towtruck,firetruck}.blend.
Reproducible Blender authoring/export: scripts/create_traffic_passenger.py, scripts/create_traffic_heavy.py, scripts/create_traffic_special.py.
The original JavaScript surface builders are authoring inputs only; the game loads the final GLBs in assets/traffic/.
See manifest.json for final binary hashes and docs/FLEET_UPDATE.md for taxonomy and gameplay envelopes.

Landscape stone detail
Original 256x256 locally generated grayscale stone tile shared by distant ridge and near-rock materials.
Trilinear mipmaps, no downloaded rock bitmap, no extra scene pass.

Wheel refinement
Original Blender-authored rounded tire carcasses, recessed alloy/steel rims, brake hardware, hub fasteners, commercial ventilation openings and dual-tire separation. Editable sources and generators are the same eight traffic projects listed above. No third-party wheel models or textures used.

Traffic cabins and mirrors
Original Blender-authored seats, dashboards, steering wheels, inner panels/headliners, cut-through window apertures, mirror panes and separate turn-signal lenses for all eight traffic vehicles. The mirrors use the project's shared sky environment, not per-vehicle live reflection cameras. No external interior or mirror texture/model was used.

Original Blender traffic drivers and interior enclosure refinement (2026-10-17)
All eight traffic vehicles include original seated adult character geometry, sealed
floors/footwells/firewalls/inner wheel housings, steering/grip/stalk markers and
articulated shoulder/elbow/hand groups. Created for this project in the editable
art/traffic/*.blend sources by scripts/create_traffic_{passenger,heavy,special}.py.
No third-party human mesh, character texture, manufacturer CAD or motion capture
was used. Lightweight stylized characters, not photoreal human representations.

Character and coupling refinement (2026-10-17)
Original Blender-authored facial features, hair, clothing seams/cuffs and curled fingers for all eight adult traffic drivers; separate lightweight neck/head pivot. Semi nose clearance rebuilt in the editable original Blender source. No external character asset, scan, animation library or manufacturer CAD used.

Swept wheel-house clearance refinement (2026-10-17)
Original Blender-authored hollow liners, formed arch walls and sealed floor transitions sized against the animated wheel envelope. Passenger body travel is bounded by measured arch compression limits. No external geometry was used.

Player live rear views: original reconstructed Blender mirror panes/backings and game-specific rear-right camera display. Left uses an original authored convex glass and bounded scene-reflection approximation; cabin uses planar scene reflection; right camera screen is user-selected and is not represented as documented factory hardware. See docs/PLAYER_MIRRORS_UPDATE.md.
